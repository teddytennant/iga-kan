IGA-KAN is a small JAX implementation of isogeometric Kolmogorov-Arnold networks from arXiv:2610.06348.
pip install -e .
python3 -m pytest
This is the safeguarded least-squares outer fit, the Bernstein basis, and the local ridge model on a 1D toy. It is not the paper's PDE solver and it does not match the reported L2 tables.
